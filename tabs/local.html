Briefly Local

采集与生成由你自己掌控，云端语音识别默认关闭、按需开启

模型接口

程序会请求 {baseUrl}/chat/completions；填完整地址也可识别。
长稿会先分块提炼要点，再汇总成一篇精华；块数越多越慢、越费 token。
：模型支持 response_format / json_object 时打开；接口报错就关掉，靠提示词约束。

语音识别

默认停用。启用后，只有在视频没有自带字幕时才会从原视频页取音频并调用云端文件转写；识别结果会缓存下来，重新生成不会重复计费。音频会被上传到你在下面填写的服务商，请确认你接受这一点。
改动自动保存，也可以点上方「保存设置」一起保存。识别服务使用「上传凭证 → 直传 → 异步任务 → 轮询」的文件转写接口；需要支持该接口的服务商密钥。任务提交后中断会接着轮询，一般不用重来；确实要重新识别时，在结果页按住 Shift 点「重新生成」（会产生新费用）。

生成历史

采集到的原文和生成结果都保存在浏览器扩展的本地存储里（不是磁盘文件），关掉标签页也不会丢。点标题可回看、重新生成、导出；删除会同时清掉该条的原文与结果。

怎么用

  • 输出样式：结果页按结构化 JSON 渲染——概览 / 核心金句 / 本片亮点（原文金句中英对照 + 词汇注解，点时间戳跳回原片）/ 核心认知 / 关键数字 / 时间线 / 推荐书单 / 全文逐字稿；支持逐字稿搜索、复制、下载 Markdown、打印成 PDF。上方提示词可直接改字段。
  • 在浏览器扩展页用「加载已解压的扩展程序」选择 briefly-local 目录；首次安装会自动打开本页。
  • 打开 YouTube / B站视频页或普通文章页，点扩展图标（或视频页的灯泡浮层）→ 生成精华版，会自动采集字幕或正文并打开本地结果页。
  • 结果页用你这里配置的模型生成中文精华，可复制、下载 Markdown、保存为独立 HTML、打印成 PDF、查看原始字幕。想长期留档，用「保存 .html」或「下载 .md」把内容落到磁盘；上方「生成历史」可随时找回之前的结果。
  • 纯本地：先启动 Ollama（ollama serve）并拉好模型；也可用 DeepSeek / SiliconFlow / 智谱等云 API，填 Key 即可。若本地模型返回 403 / CORS 错误，给 Ollama 设置 OLLAMA_ORIGINS=* 后重启。
  • YouTube 字幕由本扩展在视频页里重新读取字幕轨并抓取，所以生成时请保持原视频标签页打开；B站字幕和网页正文会随采集直接带回。
  • 没有自带字幕时：默认会提示「没有可用文本」；在上面「语音识别」里启用并填好密钥后，会先从原视频页取音频，再上传到云端做文件转写，最后按同样的精华版样式生成（原视频标签页必须保持打开）。识别结果按条目缓存在本地，重新生成不会重复提交计费；任务提交后中断会接着轮询，不会重复扣费。B站可直接取音频流；YouTube 若音频流被签名保护且没有字幕轨，目前仍不支持。
  • host_permissions 保留 <all_urls>，只为让任意模型地址和视频站点可连，想更严可自行收窄。
